# Example sweeps and dataset terms

This folder ships in the wheel, so the files below are on disk after
`pip install lasagna-rag[eval]`, under `lasagna/knowledge_evaluation_sdk/research/` in your
site-packages. Copy a sweep file, edit it, and run it with
`lasagna benchmark experiment <file>.yaml`. The walkthrough is in the
[guide](https://github.com/dolev31/lasagna/blob/main/docs/guide.md#8-measure-it-on-a-benchmark).

| File | What it runs |
| ---- | ------------ |
| [experiments/quickstart.yaml](experiments/quickstart.yaml) | The `smoke` benchmark, bundled with the package: no download, no API key. Checks that the pipeline runs end to end; its scores measure nothing |
| [experiments/beir_sweep.yaml](experiments/beir_sweep.yaml) | Three rerankers (`cross_encoder`, `combined`, `ensemble`) on `beir/nfcorpus`, `beir/scifact` and `beir/fiqa`, 200 samples each, 3 runs |
| [experiments/hyde_x_reranking.yaml](experiments/hyde_x_reranking.yaml) | A 2x2 factorial, HyDE by reranking, on `beir/scifact`; read it with `lasagna results interaction` |
| [experiments/multihop_analysis.yaml](experiments/multihop_analysis.yaml) | A 2x2 factorial, query expansion by reranking, on `beir/hotpotqa` |
| [DATASETS.md](DATASETS.md) | Each benchmark's source, license and citation. Generated by `lasagna benchmark licenses`; do not edit by hand |

Each YAML file explains in its comments what it measures and why its settings are what they
are. Results go to `~/.lasagna/research/results/<name>_<timestamp>/` unless the file sets
`output_dir`.

Lasagna redistributes no benchmark data: each dataset is downloaded from its own source, under
its own terms, the first time a run needs it. [DATASETS.md](DATASETS.md) lists those terms.

Metric definitions: [../docs/metrics.md](../docs/metrics.md). The benchmark catalogue and how to
add an adapter: [../docs/benchmarks.md](../docs/benchmarks.md).
