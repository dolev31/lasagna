# The `lasagna` package

This is the source of Lasagna. The documentation for using it is outside the
package:

- [README](../../README.md): what Lasagna is, the quickstart, and the agent setup.
- [Guide](../../docs/guide.md): write a component, compare it, measure it on a benchmark.
- [Configuration](../../docs/configuration.md): which settings apply, profiles, data, models.
- [Settings reference](../../docs/reference/settings.md): every setting, generated from the code.
- [Deployment](deploy/README.md) and the [MCP server](mcp/README.md).

Most subpackages (`core/`, `api/`, `retrieval/`, `processing/`, `agentic/`,
`vector_backends/`, `knowledge_evaluation_sdk/`, `sdk/` and others) have a short
README for contributors next to the code it describes.
[AGENTS.md](../../AGENTS.md) maps the layout.
