# Settings reference

Generated by `scripts/gen_settings_doc.py` from `src/lasagna/core/config.py` and
`src/lasagna/settings.lasagna.toml`. Do not edit by hand: run the script.

Where a setting comes from, lowest priority first:

1. the default below;
2. `settings.lasagna.toml`, `[rag]` table (`LASAGNA_SETTINGS_FILE` names another file);
3. the environment variable: `LASAGNA_<NAME>`, or `RAG_<NAME>` (the older name, still
   read; `LASAGNA_` wins when both are set);
4. the session (`lasagna configure --profile <name> -s <session>`, the REST API or MCP).

The settings file and environment variables are the process defaults. A
session's profile and overrides are kept in the session database and win over
both for that session only.

An environment variable that does not parse, or is outside the allowed values,
stops the process with an error naming it, except `log_level`, which warns and
keeps its default: it is also the `lasagna` command's console level (`WARNING`
unless set), and a typo in it must not stop `lasagna doctor`. A `RAG_` variable that is not a
setting is ignored with a warning that suggests the closest one. Booleans take
`true`/`false`, `1`/`0`, `yes`/`no` or `on`/`off`; lists and objects take JSON.

Data lives in `~/.lasagna` (`LASAGNA_DATA_DIR`): the databases in `dbs/`
(`LASAGNA_DB_DIR`) and uploads in `uploads/` (`LASAGNA_UPLOAD_DIR`). A
`~/.rag_knowledge` from an earlier version is moved there on first use.

### Paths and the process

| Variable | Default | Description |
|---|---|---|
| `LASAGNA_DATA_DIR`, `RAG_DATA_DIR` | `~/.lasagna` | Where Lasagna keeps its data. |
| `LASAGNA_DB_DIR`, `RAG_DB_DIR` | <data dir>/dbs | The databases and the local vector stores. |
| `LASAGNA_UPLOAD_DIR`, `RAG_UPLOAD_DIR` | <data dir>/uploads | Stored uploads. |

| `RAG_STORE_LOCK_TIMEOUT` | `300` | Seconds a process waits for a lock another process holds in a PostgreSQL metadata store (a document's during a reindex, a session's during a profile switch) before the operation fails and says so, with nothing changed. |

| `RAG_LANGFUSE_TRACING` | `false` | Send LLM traces to Langfuse (needs the langfuse package and its keys). |
| `RAG_LLM_CACHE_MAX_SIZE` | `50` | How many LLM clients the process keeps for reuse. |
| `RAG_CRAG_GRADING_CONCURRENCY` | `4` | Parallel relevance-grading calls in corrective RAG (CRAG). |
