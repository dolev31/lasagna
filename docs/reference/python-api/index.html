    Python API¶

    These are the names import lasagna exposes, in lasagna.__all__. The package loads each one on first use, so import lasagna stays fast.

    Decorators and registry¶

    Each stage has a decorator with the same name: lasagna.reranker, lasagna.query_enhancer, lasagna.chunker, lasagna.embedder, lasagna.retriever, lasagna.document_processor and lasagna.generator. All take the same arguments and register under the stage they are named for:

    import lasagna

@lasagna.reranker                      # name taken from the function
def by_length(query, text): ...

@lasagna.reranker("keyword_overlap")   # explicit name
def keyword_overlap(query, text): ...

lasagna.reranker("by_length_2", by_length)   # a call, not a decorator

    Each accepts paper=, claims= and version= keywords, which a run records as the component's provenance. The function each stage expects is listed in write a component.

    register ¶

    register(
    stage: str,
    obj: Any,
    name: Optional[str] = None,
    *,
    paper: Optional[str] = None,
    claims: Optional[dict] = None,
    version: Optional[str] = None,
) -> Any

    Register a function or class as a stage component; returns obj.

    Built-in names are refused: a function registered as cross_encoder would replace the control arm of every sweep in the process, under the built-in's name and provenance. Re-registering one of your own names replaces it, so a notebook cell can be run again.

    The registry holds every component, built in or yours. from lasagna.core.registry import registry gives you the shared instance (also lasagna.registry).

    ComponentRegistry ¶

    ComponentRegistry()

    Unified registry for RAG pipeline components.

    Thread-safe singleton that stores component implementations by type and name. Supports both decorator-based and imperative registration for a clean researcher workflow.

    Category aliasing: "enhancer" and "query_enhancer" refer to the same slot so that both the core and retrieval APIs work transparently.

    list_components ¶

    list_components(
    component_type: Optional[str] = None,
) -> List[Dict[str, Any]]

    Every listed component of one stage or all, with what it declares.

    Each entry is what the stage's list_* helper returns, plus stage and builtin. Stages are in name order. Imports no component, so it is safe for a CLI listing.
