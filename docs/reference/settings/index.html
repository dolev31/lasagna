    Settings reference¶

    Generated by scripts/gen_settings_doc.py from src/lasagna/core/config.py and src/lasagna/settings.lasagna.toml. Do not edit by hand: run the script.

    Where a setting comes from, lowest priority first:

    1. the default below;
    2. settings.lasagna.toml, [rag] table (LASAGNA_SETTINGS_FILE names another file);
    3. the environment variable: LASAGNA_<NAME>, or RAG_<NAME> (the older name, still read; LASAGNA_ wins when both are set);
    4. the session (lasagna configure --profile <name> -s <session>, the REST API or MCP).

    The settings file and environment variables are the process defaults. A session's profile and overrides are kept in the session database and win over both for that session only.

    An environment variable that does not parse, or is outside the allowed values, stops the process with an error naming it, except log_level, which warns and keeps its default: it is also the lasagna command's console level (WARNING unless set), and a typo in it must not stop lasagna doctor. A RAG_ variable that is not a setting is ignored with a warning that suggests the closest one. Booleans take true/false, 1/0, yes/no or on/off; lists and objects take JSON.

    Data lives in ~/.lasagna (LASAGNA_DATA_DIR): the databases in dbs/ (LASAGNA_DB_DIR) and uploads in uploads/ (LASAGNA_UPLOAD_DIR). A ~/.rag_knowledge from an earlier version is moved there on first use.

    chunk_size int, 1 to 100000 800 LASAGNA_CHUNK_SIZE, RAG_CHUNK_SIZE How large each piece of content should be (in characters). Smaller = more precise, larger = more context.

    semantic_breakpoint_method str "absolute" LASAGNA_SEMANTIC_BREAKPOINT_METHOD, RAG_SEMANTIC_BREAKPOINT_METHOD How the semantic chunker picks breakpoints: 'absolute' or a Kamradt method.
    semantic_breakpoint_amount float or none none LASAGNA_SEMANTIC_BREAKPOINT_AMOUNT, RAG_SEMANTIC_BREAKPOINT_AMOUNT The breakpoint method's parameter; None uses the method's default.
    semantic_buffer_size int 1 LASAGNA_SEMANTIC_BUFFER_SIZE, RAG_SEMANTIC_BUFFER_SIZE Neighbouring sentences embedded with each sentence, on either side.
    min_chunk_size int 200 LASAGNA_MIN_CHUNK_SIZE, RAG_MIN_CHUNK_SIZE Pieces smaller than this are merged with their neighbors.
    max_chunk_size int 1500 LASAGNA_MAX_CHUNK_SIZE, RAG_MAX_CHUNK_SIZE Pieces larger than this are force-split to keep them manageable.
    window_size int 3 LASAGNA_WINDOW_SIZE, RAG_WINDOW_SIZE Number of sentences per chunk in sentence_window strategy.
    sentence_overlap int 1 LASAGNA_SENTENCE_OVERLAP, RAG_SENTENCE_OVERLAP Number of sentences to overlap in sentence_window strategy.
    enable_hierarchical bool true LASAGNA_ENABLE_HIERARCHICAL, RAG_ENABLE_HIERARCHICAL Keeps related pieces of a document together so answers include full context, not just fragments.
    parent_chunk_size int 2000 LASAGNA_PARENT_CHUNK_SIZE, RAG_PARENT_CHUNK_SIZE Size of the broader context pieces (in characters). Provides surrounding context when needed.
    child_chunk_size int 500 LASAGNA_CHILD_CHUNK_SIZE, RAG_CHILD_CHUNK_SIZE Size of the precise matching pieces (in characters). Used for initial search.
    auto_merge_threshold float 0.5 LASAGNA_AUTO_MERGE_THRESHOLD, RAG_AUTO_MERGE_THRESHOLD When enough small pieces match from the same section, automatically use the full section instead.
    enable_late_chunking bool false LASAGNA_ENABLE_LATE_CHUNKING, RAG_ENABLE_LATE_CHUNKING Late chunking: embed full doc, pool per chunk (Jina, arxiv:2409.04701)
    late_chunking_overlap int 512 LASAGNA_LATE_CHUNKING_OVERLAP, RAG_LATE_CHUNKING_OVERLAP Tokens shared by consecutive windows in long late chunking.
    chunk_unit str "chars" LASAGNA_CHUNK_UNIT, RAG_CHUNK_UNIT What chunk_size and chunk_overlap count: 'chars', 'words' or 'tokens'.
    chunk_tokenizer str or none none LASAGNA_CHUNK_TOKENIZER, RAG_CHUNK_TOKENIZER Tokenizer for chunk_unit='tokens': a Hugging Face name, or 'tiktoken:'.
    recursive_separators list ["\n\n", "\n", ". ", "? ", "! ", " ", ""] LASAGNA_RECURSIVE_SEPARATORS, RAG_RECURSIVE_SEPARATORS Separators the recursive chunker tries, coarsest first.
    recursive_keep_separator str "end" LASAGNA_RECURSIVE_KEEP_SEPARATOR, RAG_RECURSIVE_KEEP_SEPARATOR Whether a separator ends the piece before it ('end') or starts the next ('start').
    markdown_header_levels int 6 LASAGNA_MARKDOWN_HEADER_LEVELS, RAG_MARKDOWN_HEADER_LEVELS Deepest Markdown header level the markdown_header chunker splits on (1-6).
    markdown_strip_headers bool true LASAGNA_MARKDOWN_STRIP_HEADERS, RAG_MARKDOWN_STRIP_HEADERS Leave header lines out of markdown_header chunk text (they are in metadata).
    markdown_split_long_sections bool true LASAGNA_MARKDOWN_SPLIT_LONG_SECTIONS, RAG_MARKDOWN_SPLIT_LONG_SECTIONS Split Markdown sections longer than chunk_size with the recursive chunker.
    proposition_model str or none none LASAGNA_PROPOSITION_MODEL, RAG_PROPOSITION_MODEL LLM that writes propositions; None uses the configured default.
    proposition_passage_size int 100 LASAGNA_PROPOSITION_PASSAGE_SIZE, RAG_PROPOSITION_PASSAGE_SIZE Words per passage the proposition chunker hands to the LLM.
    contextual_base_chunker str "recursive" LASAGNA_CONTEXTUAL_BASE_CHUNKER, RAG_CONTEXTUAL_BASE_CHUNKER Registered chunker whose chunks the contextual chunker situates.
    contextual_model str or none none LASAGNA_CONTEXTUAL_MODEL, RAG_CONTEXTUAL_MODEL LLM that writes each chunk's context; None uses the configured default.
    contextual_max_document_chars int or none 50000 LASAGNA_CONTEXTUAL_MAX_DOCUMENT_CHARS, RAG_CONTEXTUAL_MAX_DOCUMENT_CHARS Characters of the document in each context prompt; None for all of it.
    preserve_tables bool true LASAGNA_PRESERVE_TABLES, RAG_PRESERVE_TABLES Prevents tables from being split across multiple pieces.
    preserve_headers bool true LASAGNA_PRESERVE_HEADERS, RAG_PRESERVE_HEADERS Attaches section headings to their content so context is never lost.
    extract_metadata bool true LASAGNA_EXTRACT_METADATA, RAG_EXTRACT_METADATA keep page, section and file metadata on each chunk.
    max_file_size int 52428800 LASAGNA_MAX_FILE_SIZE, RAG_MAX_FILE_SIZE 50MB.
    max_content_length int 4000 LASAGNA_MAX_CONTENT_LENGTH, RAG_MAX_CONTENT_LENGTH Maximum content length per chunk in storage (characters).

    Hybrid Search¶

    Setting Type Default Environment variables Description
    enable_hybrid_search bool true LASAGNA_ENABLE_HYBRID_SEARCH, RAG_ENABLE_HYBRID_SEARCH Finds results by both meaning and exact keywords, so it catches acronyms, IDs, and rare terms that pure AI search misses.
    hybrid_alpha float, 0.0 to 1.0 0.7 LASAGNA_HYBRID_ALPHA, RAG_HYBRID_ALPHA Balance between understanding meaning (right) and matching exact words (left). Most documents work best around 0.7.
    sparse_method str "bm25" LASAGNA_SPARSE_METHOD, RAG_SPARSE_METHOD Which keyword-based retrieval method to use alongside AI vector search.
    default_top_k int, 1 to 10000 20 LASAGNA_DEFAULT_TOP_K, RAG_DEFAULT_TOP_K Research: 75+ introduces hard negatives (ICLR 2025)
    similarity_threshold float, 0.0 to 1.0 0.3 LASAGNA_SIMILARITY_THRESHOLD, RAG_SIMILARITY_THRESHOLD Cut applied to the per-query normalized score when the agentic loop or an evaluation's generation track searches.     rrf_k int 60 LASAGNA_RRF_K, RAG_RRF_K RRF constant for Reciprocal Rank Fusion.
    enable_bm25_stemming bool true LASAGNA_ENABLE_BM25_STEMMING, RAG_ENABLE_BM25_STEMMING Enable Porter stemming for BM25.
    bm25_max_sessions int 1000 LASAGNA_BM25_MAX_SESSIONS, RAG_BM25_MAX_SESSIONS Maximum number of in-memory BM25 session indices to keep.
    bm25_session_ttl_seconds int 86400 LASAGNA_BM25_SESSION_TTL_SECONDS, RAG_BM25_SESSION_TTL_SECONDS Idle TTL for BM25 session indices in seconds.
    bm25_k1 float 1.2 LASAGNA_BM25_K1, RAG_BM25_K1 BM25 term-frequency saturation for the bm25 and hybrid retrievers.
    bm25_b float 0.75 LASAGNA_BM25_B, RAG_BM25_B BM25 document-length normalisation for the bm25 and hybrid retrievers.

    self_rag_retrieval str "adaptive" LASAGNA_SELF_RAG_RETRIEVAL, RAG_SELF_RAG_RETRIEVAL Self-RAG: 'adaptive' (the model judges) or 'always' retrieve.
    enable_mmr bool true LASAGNA_ENABLE_MMR, RAG_ENABLE_MMR Avoids showing repetitive or near-duplicate results, so answers draw on varied sources.
    mmr_lambda float, 0.0 to 1.0 0.5 LASAGNA_MMR_LAMBDA, RAG_MMR_LAMBDA LangChain and LlamaIndex default; a pre-MMR filter keeps only relevant items.
    mmr_score_normalization str "sigmoid" LASAGNA_MMR_SCORE_NORMALIZATION, RAG_MMR_SCORE_NORMALIZATION MMR score normalization strategy.

    Variables that are not settings¶

    The servers, the MCP server and the vector stores read these from the environment only: not from the settings file, and not per session.

    REST API and authentication¶

    Variable Default Description
    RAG_REQUIRE_AUTH false When true, only a verified X-Session-Token names a session, and POST /api/v1/sessions needs an X-API-Key. When false, binding beyond loopback is refused at startup unless RAG_BIND_IS_PROTECTED is set.
    RAG_API_KEYS unset Comma-separated keys, each at least 32 characters, that may mint session tokens when RAG_REQUIRE_AUTH is on. Rate limits and quotas are counted per key, over all the sessions it minted.
    RAG_JWT_SECRET a random secret per process Signs session tokens (HMAC-SHA256). Unset, tokens stop working when the process restarts; with RAG_REQUIRE_AUTH on, an unset, placeholder or shorter-than-32-character secret stops the server at startup.
    RAG_SESSION_TOKEN_TTL_SECONDS 604800 How long a session token is valid, in seconds (7 days).
    RAG_ADMIN_TOKEN unset The X-Admin-Token for /api/v1/admin/* and for naming a session in POST /api/v1/sessions. Unset, a placeholder or shorter than 32 characters: the admin routes answer 503.
    RAG_ALLOW_ANONYMOUS_SESSION false With RAG_REQUIRE_AUTH on, keep the anonymous default session usable.
    RAG_BIND_IS_PROTECTED false Says that something outside the process (a loopback port mapping, a NetworkPolicy, a firewall) restricts access, so the server may bind beyond loopback with auth off.
    RAG_ALLOW_HEADER_IDENTITY false Accept the X-User-ID header as the user identity; otherwise it is refused with 401.
    RAG_CORS_ORIGINS empty Comma-separated origins allowed cross-origin requests (REST and MCP over HTTP). Empty allows none; * is refused at startup when RAG_REQUIRE_AUTH is on.
    RAG_ALLOWED_HOSTS unset Extra Host names the REST API and MCP over HTTP answer to with auth off, comma-separated (name, or name:* for any port), such as a container's service name. Otherwise only localhost, 127.0.0.1 and [::1].
    RAG_FORWARDED_ALLOW_IPS 127.0.0.1 Proxy addresses whose X-Forwarded-For is trusted. The image reads gunicorn's FORWARDED_ALLOW_IPS first.
    RAG_MAX_BATCH_FILES 20 Files in one POST /api/v1/documents/batch; more is refused with 400.
    RAG_MAX_BATCH_BYTES 209715200 Total body of one batch upload (200 MiB); more is refused with 413 before the body is read.
    RAG_SEARCH_TIMEOUT 120 Seconds a REST search may run before it answers 504.
    RAG_MAX_SESSIONS_PER_KEY 100 With RAG_REQUIRE_AUTH on, how many sessions one API key may mint per token lifetime (RAG_SESSION_TOKEN_TTL_SECONDS); one more answers 429. Raise it for an application that makes a session per end user.
    RAG_EMBED_MCP false Mount the MCP server at /mcp inside the REST process, for single-process deployments such as Milvus Lite.
    RAG_CONFIGURATOR false Mount the configurator UI at /configurator, with its API routes.
    LASAGNA_LOG_FORMAT text json writes one JSON object per log line; text shows a request's id before the message. Any other value stops the server at startup.
    PROMETHEUS_MULTIPROC_DIR unset The directory gunicorn workers share for Prometheus metrics (set in the image).
    RAG_WORKER_METRICS_PORT unset The port a Celery worker serves its Prometheus /metrics on, with RAG_ENABLE_PROMETHEUS on (lasagna_ingests_total for the documents it processed). Unset, the worker serves none. Compose and Kubernetes set 9100.
