    Components¶

    Generated by scripts/gen_catalog_doc.py from the component and benchmark registries. Do not edit by hand: run the script.

    55 components ship with the package, across eight stages. Name one in a sweep, or run one with lasagna benchmark run <benchmark> --reranker <name>. The same list prints from lasagna component list.

    The last column is what the component needs beyond pip install lasagna-rag. "An LLM" means the run's LLM, set up as in Installation. "Downloads a model" means the weights come from the Hugging Face Hub on first use (see Model licenses). Extras are listed in Installation.

    Document processor¶

    4 built in. Swap this stage to change how files are parsed into text. Contract: BaseDocumentProcessor.

    Name What it does Source Needs
    default Built-in extraction (pypdf and pdfplumber, OCR when enabled) Nothing extra
    docling Docling layout analysis, TableFormer tables and OCR, exported as Markdown arXiv:2408.09869 pip install 'lasagna-rag[docling]'
    markitdown Microsoft MarkItDown: PDF, Office, HTML and more to Markdown github.com pip install 'lasagna-rag[markitdown]'
    pymupdf4llm PyMuPDF4LLM: PDF to Markdown with headers and tables (AGPL-3.0) github.com pip install 'lasagna-rag[pymupdf4llm]' (AGPL-3.0)
