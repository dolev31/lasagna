# Components

Generated by `scripts/gen_catalog_doc.py` from the component and benchmark
registries. Do not edit by hand: run the script.

55 components ship with the package, across eight stages. Name one in a
sweep, or run one with `lasagna benchmark run <benchmark> --reranker <name>`. The same
list prints from `lasagna component list`.

The last column is what the component needs beyond `pip install lasagna-rag`. "An LLM" means the run's LLM, set up as in [Installation](../get-started/installation.md#an-llm-for-the-generation-track). "Downloads a model" means the weights come from the Hugging Face Hub on first use (see [Model licenses](../project/model-licenses.md)). Extras are listed in [Installation](../get-started/installation.md#extras).
